# Sécurité · Security

Vous pensez avoir trouvé une faille dans ce programme ? Merci de ne pas ouvrir de ticket public : utilisez le bouton **Report a vulnerability** de l'onglet [Security](https://github.com/Ergalo/scanner-parc/security) de ce dépôt (signalement privé). Nous répondons sous cinq jours ouvrés.

Found a vulnerability? Please do not open a public issue: use **Report a vulnerability** in this repository's [Security](https://github.com/Ergalo/scanner-parc/security) tab (private report). We answer within five business days.
